# AI-Powered Merchant Expense Anomaly & Risk Analyzer

A real-time financial transaction evaluation microservice and UI dashboard designed to detect anomalies, off-hours spikes, and cross-border currency risks.

## Features
- **Heuristic Risk Engine:** Scores transaction risk based on monetary thresholds, time-of-day execution spikes, and currency conversions.
- **RESTful API Pipeline:** Ingests batch JSON payloads and returns structured risk indicators.
- **Diagnostic UI:** Responsive Tailwind CSS interface with dynamic alert rendering.

## Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** HTML5, JavaScript (ES6+), Tailwind CSS
- **Data Format:** JSON
